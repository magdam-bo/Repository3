# 鳥籠の聖堂（仮）

ブラウザで動く、Phaser 3製の探索型ホラー脱出ゲームの試作版です。GitHub Pagesではリポジトリの `main` ブランチ / root を公開対象に設定します。

## 操作
- 移動：矢印キー / WASD
- 調べる・決定：Z / Enter
- 持ち物：I
- 戻る・メニュー：X / Escape
- スマートフォン：画面内の方向パッド、調べる、持ち物ボタン

## 試作範囲
大聖堂と小部屋、調査・会話、4桁の仮暗証番号（1842）、所持品、アイテム使用、ルサイの3状態、localStorageセーブを実装。

小部屋で書類を読み、大聖堂の棚を開けて鉄の鍵を入手します。鍵で小部屋の机の引き出しを開けると針金を取れます。針金はルサイの近くで使用します。暗証番号と台詞は試作版用の仮設定です。
